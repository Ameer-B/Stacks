# Stack — Introductory Implementation (C#)

A minimal, beginner-friendly implementation of a **Stack** in C#.  
This project demonstrates the basic behavior of a LIFO (Last-In, First-Out)  
data structure using simple push, pop, and peek operations.

---

## Features
- Push items onto the stack  
- Pop items from the stack  
- Peek at the top item  
- Check if the stack is empty  
- Clean, easy-to-read code structure

---

## Concept
A stack processes elements in reverse order of insertion:

**Last In → First Out**

Stacks are commonly used in:
- Expression evaluation  
- Undo/redo systems  
- Call stacks  
- Depth-first search (DFS)

---

## Purpose
A small introductory project to understand how stacks work and how to implement  
them from scratch using basic C# logic.
